# Customer-facing features

A modern task management application that combines intuitive block-style editing with powerful time management capabilities. Built for productivity-focused users who want a clean, efficient way to organize and track their tasks.

## Task Management

### Block-style Editing
Click anywhere to edit tasks inline with automatic saving. No need to double-click or enter edit mode - just click and start typing. Changes are saved automatically as you type, providing a seamless editing experience that feels natural and responsive.

**Entry points:** Main task list interface
**Limitations:** Currently in development

### Drag & Drop Organization
Seamlessly reorganize tasks by dragging them to new positions. Move tasks between different time periods or reorder them by priority with simple drag and drop gestures. Visual feedback shows where tasks will be placed before you drop them.

**Entry points:** Main task list interface
**Limitations:** Currently in development

### Status Tracking
Complete task lifecycle management from creation to completion. Mark tasks as in-progress, completed, or archived. Visual indicators show task status at a glance, helping you stay organized and track your progress.

**Entry points:** Task list items, status dropdowns
**Limitations:** Currently in development

## Technical Features

### Auto-save
Never lose your work with automatic saving. All changes are saved instantly as you type, so you can focus on your tasks without worrying about losing progress.

**Entry points:** All editing interfaces
**Limitations:** Currently in development

### RESTful API
Robust backend API built with Express and TypeScript. Fast, reliable data synchronization between your devices with proper error handling and data validation.

**Entry points:** Backend API (http://localhost:3001/api/)
**Limitations:** Currently in development

### SQLite Database
Lightweight, fast local database that works offline. Your data is stored securely and efficiently, with no external dependencies or cloud requirements.

**Entry points:** Backend database
**Limitations:** Currently in development
